### 🩺 Pulse — the project I'm proudest of

A **WHOOP-style recovery dashboard** for Apple Watch data, built native in SwiftUI (iOS 17+, zero dependencies).

It reads HealthKit and computes **recovery, strain, and sleep** scores entirely **on-device** — no account, no backend, nothing leaves the phone. I designed the scoring math (z-scores against personal rolling baselines), the data pipeline, and a deliberately quiet, instrument-grade UI.

- 📊 **Live overview:** https://william-t-christie.github.io/pulse/
- 💻 **Code:** https://github.com/William-T-Christie/pulse
